# Triage Labels

Use these strings for the five canonical triage roles in local ticket `Status:` lines.

| Role | Local status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the ticket. |
| `needs-info` | `needs-info` | Waiting for required information or approval. |
| `ready-for-agent` | `ready-for-agent` | Fully specified for agent work once blocking tickets are complete. |
| `ready-for-human` | `ready-for-human` | Requires a human action. |
| `wontfix` | `wontfix` | Will not be actioned. |

Edit the local-status column if this repository adopts a different vocabulary.
