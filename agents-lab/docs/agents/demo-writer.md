# Synthetic report writer

Use this role in its own Codex session for the Mac synthetic weekly-report pilot.

1. Read the source task and require `status: ready`. Run its artifact verification before drafting.
2. Run the draft entry point documented in `README.md`. Inspect the generated report and tracked draft task.
3. Commit the draft task in `working` state and hand the task path to a separate reviewer session.

Use only values present in the checked evidence. Keep unavailable historical values as `—`. Leave source evidence, the source task, and review results to their owning phases. A draft is never an acceptance or an external message.
