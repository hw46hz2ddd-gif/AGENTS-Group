# 04 — 真实周报草稿与人工验收门禁

**What to build:** 用户对已核对的历史周数据得到可审阅的周报草稿和独立复核结果，并能明确决定是否验收特定版本及其证据。实际验收决定始终由用户作出。

**Blocked by:** 02 — 合成周报草稿与独立复核；03 — 真实历史周的数据口径与只读核对

**Category:** enhancement

**Status:** needs-info

**State:** open

- [ ] 草稿使用已批准的口径与通过核对的证据；所有数字可追溯到该周输入。
- [ ] 独立复核发现错误数字、口径偏差或证据缺口时，版本保持退回状态。
- [ ] 人工验收界面或操作要求明确的用户决定，并记录草稿版本、证据和决定；未获决定的草稿不显示为 Accepted。
- [ ] 在 Mac 上演示一份真实历史周草稿的复核和验收门禁；演示或测试用决定不代表用户已接受实际周报，也不向外部发送。
