# 02 — 合成周报草稿与独立复核

**What to build:** 用户从通过来源审查的合成周数据得到带证据引用的周报草稿，并得到一份独立复核结论；错误数字或缺失证据会阻止草稿进入可验收状态。

**Blocked by:** 01 — 来源审查与任务账本

**Category:** enhancement

**Status:** ready-for-agent

**State:** closed

- [x] 草稿中的数字可回溯到本轮已通过的证据，缺失值明确写为 `—`，不推算数字。
- [x] 独立复核核对草稿数字、口径和证据引用，输出可定位的通过或退回结论。
- [x] 人为改错一处草稿数字后，复核会退回该版本，账本不会把它标为完成。
- [x] 在 Mac 上演示从合成输入到草稿、复核结论和任务状态的完整链路。
